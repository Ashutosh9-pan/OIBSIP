# OIBSIP — Oasis Infobyte Web Development Internship

This repository contains the projects completed as part of the **Oasis Infobyte Web Development & Designing Internship**.

I completed **Level 2**, which includes four web development projects focused on building responsive interfaces, JavaScript functionality, browser storage, and authentication concepts.

---

## 🚀 Level 2 Projects

### 1. 🧮 CalcPro — Calculator

A modern and responsive calculator web application designed to perform basic arithmetic operations through a clean and user-friendly interface.

**Features**
- Addition, subtraction, multiplication, and division
- Percentage and decimal calculations
- Clear and delete functionality
- Keyboard support
- Responsive calculator interface
- Error handling

**Tech Stack:** HTML5, CSS3, Vanilla JavaScript

### 2. 📚 Srinivasa Ramanujan Tribute Page

A responsive tribute website dedicated to **Srinivasa Ramanujan**, highlighting his life, mathematical achievements, legacy, and the famous Ramanujan number 1729.

**Features**
- Responsive hero section
- Biography and achievements
- Ramanujan Number 1729 section
- Mathematical equation cards
- Life and achievement timeline
- Quote and legacy sections
- Responsive desktop and mobile design

**Tech Stack:** HTML5, CSS3

🌐 **Live Demo:**  
[View Tribute Page Live](https://ashutosh9-pan.github.io/OIBSIP/WebDev-L2-TributePage/)

📂 **Project Folder:**

### 3. ✅ TaskNest — To-Do Web App

A responsive task management application that allows users to organize pending and completed tasks with persistent browser storage.

**Features**
- Add new tasks
- Edit tasks inline
- Delete tasks
- Mark tasks as completed or pending
- Separate Pending and Completed sections
- Pending, Completed, and Total counters
- Creation and completion timestamps
- Local Storage persistence
- Responsive desktop and mobile interface

**Tech Stack:** HTML5, CSS3, Vanilla JavaScript, Local Storage

🌐 **Live Demo:**  
[View TaskNest Live](https://ashutosh9-pan.github.io/OIBSIP/WebDev-L2-ToDoApp/)

📂 **Project Folder:**  
[`WebDev-L2-ToDoApp`](./WebDev-L2-ToDoApp)

---

### 4. 🔐 SecureNest — Login Authentication System

A client-side authentication project featuring account registration, login validation, protected dashboard access, and session management.

**Features**
- User registration
- Username and email validation
- Password validation
- Duplicate account detection
- Login using username or email
- Show/Hide password
- Protected dashboard
- Unauthorized access redirect
- Login session management
- Logout functionality
- Responsive interface

**Tech Stack:** HTML5, CSS3, Vanilla JavaScript, Local Storage, Session Storage, Web Crypto API

🌐 **Live Demo:**  
[View SecureNest Live](https://ashutosh9-pan.github.io/OIBSIP/WebDev-L2-LoginAuthentication/)

📂 **Project Folder:**  
[`WebDev-L2-LoginAuthentication`](./WebDev-L2-LoginAuthentication)

> **Note:** SecureNest is an educational client-side authentication demonstration. Production applications should use secure server-side authentication and protected databases.
